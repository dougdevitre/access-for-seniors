# Contributing to Access For Seniors

Access For Seniors is open-source under MIT and part of the **Access To** civic tech initiative. Contributions from mission-aligned collaborators are welcome.

## How to Contribute

1. Fork the repo
2. Create a feature branch from `main`
3. Make changes with clear commit messages
4. Open a Pull Request with description of changes
5. Request review from @dougdevitre
6. All PRs require CI pass before merge

## Code Standards

- TypeScript for all Node.js and React code
- Follow existing patterns in the codebase
- Include tests for new features
- Update relevant reference docs in `references/` when changing architecture
- Security-first: encrypt PHI, validate auth, scope to tenant
- Plain language and person-first voice in user-facing content

## Access To Values

Contributions should align with Access To initiative values:
- **Equity** — design for the people with the most to gain, least to spare
- **Trauma-informed** — respect autonomy, avoid triggers, offer options
- **Community-grounded** — work with, not around, the organizations serving seniors
- **Evidence-based** — cite primary sources (ACL, CMS, CDC, peer-reviewed research)
- **Plain language** — default to how people actually talk

## Reporting Issues

Use the issue templates in `.github/ISSUE_TEMPLATE/`.
