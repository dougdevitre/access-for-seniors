# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Access For Seniors, please report it responsibly.

**Email:** dougdevitre@gmail.com
**Subject:** [SECURITY] Access For Seniors Vulnerability Report

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

**Do not** open a public GitHub issue for security vulnerabilities.

## Response Timeline

- Acknowledgment: within 48 hours
- Initial assessment: within 7 days
- Fix target: within 30 days for critical issues

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |
